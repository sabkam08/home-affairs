# HomeAffairs

A secure, enterprise-grade Home Affairs Case and Document Management System built using ASP.NET Core.

## Objectives

The system enables:

- Citizens to submit applications online
- Practitioners to process applications
- Secure document management
- Workflow-driven approvals
- Full audit trails
- Version-controlled records
- Search and document retrieval
